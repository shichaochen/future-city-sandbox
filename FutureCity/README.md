# 未来城市沙盘 · ESP32 控制程序

手机 WiFi 控制未来城市沙盘的灯光、雾化器、风力发电机与列车效果。

## 快速上手

1. Arduino IDE 里安装库：FastLED（库管理器搜索 FastLED）。
2. 板型选 ESP32 Dev Module，端口选好，上传 FutureCity.ino。
3. 手机连入 WiFi：名称 `FutureCity`，密码 `future123`。
4. 浏览器打开 `192.168.4.1`，出现深色霓虹风控制界面。
5. 上电默认进入“未来夜景”演示模式；点 ⏻ 总控可一键全开 / 全关。

## 控制一览（界面上每个按键都有图示）

- ⏻ 系统总控：一键全开 / 全关。关时灯带、雾化器、风机全部停止；再开时回到“未来夜景”。
- 🚄 列车启动 / ⏹ 列车停止：1 段流水灯，亮点带拖尾，模拟列车飞驰；速度滑块 1–10 档。
- 💡 1 段：关闭 / 常亮 / 流水灯 / 彩虹四种模式。
- ✨ 2–5 段：霓虹呼吸灯，每段独立开关，点色点换颜色。
- 💧 雾化器：继电器开关，湖面起雾。
- 🌀 风力发电机：开关 + 转速滑块（PWM 调速）。
- 🎬 演示模式 3 种：
  - 🌃 未来夜景：慢速列车 + 霓虹呼吸 + 雾 + 慢速风机。
  - 🚀 列车飞驰：高速流水灯 + 快呼吸 + 雾 + 高速风机。
  - 🌈 梦幻霓虹：全段彩虹流动 + 雾 + 中速风机。

## 接线（详见 WIRING.md）

- 灯带数据线 → GPIO 18（串 330Ω 电阻），灯带用独立 5V 6A 电源，与 ESP32 共地。
- 雾化器继电器 → GPIO 26（默认高电平触发）。
- 风机 MOSFET → GPIO 27（PWM 调速）。
- 灯带分段由代码顶部的 SEG1_LEDS（1 段灯数，默认 60）和 SEG_LEN（2–5 段每段灯数，默认 5）决定，总数自动算出；改灯数只改这两个常量。

## 常见问题

- 灯不亮：先查 5V 电源是否够力（默认 80 灯全亮约 4.8A，灯数改了按每灯 60mA 重算）、灯带地线是否与 ESP32 共地、数据线是否串了 330Ω 电阻。
- 搜不到 FutureCity：确认程序上传成功，串口监视器（115200）看是否打印 AP IP。
- 继电器不动作：有些继电器模块是低电平触发，把代码顶部的 RELAY_ON 改成 LOW 再上传。
- 颜色顺序不对（红绿颠倒）：把 FastLED.addLeds 里的 GRB 改成 RGB 再上传。

## 说明

- 本程序未在实物上验证，仅在本机通过 arduino-cli 编译；请先在桌面上接好线、通电测试，再装进沙盘。
- 若用 5 条独立灯带而不是 1 条灯带，需改数据引脚与分段映射（见 WIRING.md 末尾）。
