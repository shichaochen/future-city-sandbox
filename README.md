# 未来城市沙盘

未来城市沙盘模型：真空管道列车与高楼大厦，ESP32 控制灯光、雾化器与风力发电机，手机通过 WiFi 控制。

## 控制程序

见 [FutureCity/](FutureCity/) 目录：

- `FutureCity.ino`：ESP32 控制程序（WS2812B 五段灯带、雾化器、风机、列车流水灯、3 种演示模式）
- `README.md`：快速上手与控制一览
- `WIRING.md`：接线说明

## 使用

手机连入 WiFi `FutureCity`（密码 `future123`），浏览器打开 `192.168.4.1`，即可打开深色霓虹风控制界面。
